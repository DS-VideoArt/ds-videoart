# ביט ובורג: אתר הדגמה (עסק בדיוני)

אתר הדגמה של DS Creative Studio שממחיש אתר תדמית של עד 6 עמודי תוכן סטנדרטיים (החבילה שמתחילה ב־1,290 ₪).
ביט ובורג היא מעבדת מחשבים מומצאת. אין לה כתובת, טלפון או לקוחות, וכל הנתונים, ההמלצות והמחירים באתר הם המחשה.

- עמודי תוכן: בית, תיקונים, מחשבים חדשים, מחשבים מחודשים, ציוד נלווה, אודות ויצירת קשר. עמוד תשתית: מדיניות פרטיות.
- בלי חיפוש, בלי סינון ובלי קטלוג דינמי (הוסרו ב־25.9.2026 כי הם מחוץ לחבילה הבסיסית). הטפסים הם טפסי הדגמה שלא שולחים ולא שומרים דבר.
- noindex בכל האתר (מטא וכותרת X-Robots-Tag).
- אתר חי: https://bit-uborg-demo.netlify.app (Netlify site c150289c, שמו הקודם comfix-computer-lab-demo).

## בנייה
```bash
npm ci
npm run build:static   # netlify-dist/
npm test               # בדיקות HTML מרונדר
```
התבנית המקורית: vinext-starter (Next על vinext). תיקיית המקור עדיין נקראת comfix, זה שם פנימי בלבד.
